## English

I’m a Master’s student at **NAIST (Ubiquitous Computing Systems Lab)**.  
My focus is **privacy-preserving, non-visual human activity recognition** in smart-home scenarios using **self-supervised / contrastive representation learning**.

**What I like building**
- End-to-end prototypes: sensing → learning → application/demo
- Time-series modeling + practical system integration (IoT / smart home)

### Featured Projects
- **Multi-scene Smart Home Security (ESP8266, MQTT)**  
  A distributed, multi-module security system for home scenarios (sensor modules + control + alerts).  
  Repo: https://github.com/XiaoTechJourney/multiscene-smart-home-security-esp8266

- **Self-Supervised HAR for Smart Homes (BYOL-style SSL)**  
  Self-supervised pipeline for time-series sensor representation learning and activity recognition.  
  Repo: https://github.com/XiaoTechJourney/smart-home-activity-ssl

- **Home Assistant Add-ons / Tools**  
  Small utilities and add-ons for smart-home experiments and deployment.  
  Repo: https://github.com/XiaoTechJourney/my-ha-addons

## 日本語

奈良先端科学技術大学院大学（NAIST）・泛在计算研究室の修士学生です。  
スマートホーム環境における **非映像（プライバシー配慮）センシング** を対象に、**自己教師あり学習／対照学習** を用いた **行動認識（HAR）** を研究しています。

**得意・やりたいこと**
- センサデータ → 学習 → デモ/アプリまでの一気通貫プロトタイプ
- 時系列表現学習と、IoT/スマートホームへの実装・統合
